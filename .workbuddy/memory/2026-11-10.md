## 页脚对齐修复

- 问题（1440 宽）：三列链接列宽由内容决定（仅 98px）挤在左侧，右侧版本卡片被 `justify-between` 推到最右，中间空出 233px 空洞；品牌名因 logo 40px 与 h3 20px 顶对齐，比列标题低约 10px。
- 改法：`Layout.astro` 页脚上半部由「flex + 内层 grid」改为单一五列网格 `lg:grid-cols-[minmax(210px,1.3fr)_repeat(3,minmax(0,1fr))_auto]`；品牌行和三个 h3 统一 `h-10 flex items-center` 保证基线齐平；卡片改 `lg:justify-self-end`。

- 英文文案 `footer.updateModal.title` 由 `Get the latest TaoSheng`（158px）改为 `Get latest version`，否则 1024 宽下该链接折成两行、破坏列内行距。

## 统一用 npm，清理 pnpm 与锁文件

- 删除 `pnpm-lock.yaml`、`pnpm-workspace.yaml`，`.gitignore` 去掉 `pnpm-debug.log*`；包管理只保留 npm + `package-lock.json`。
- 原 `package-lock.json` 是从参考站拷来的（`name: magenta-motion`，含已不存在的 `@astrojs/alpinejs`），必须重新生成。直接 `npm install` 报 `@rollup/plugin-typescript` 冲突——原因是拷贝来的 `node_modules` 里残留该包，npm 把它当成根依赖。清空 `node_modules` 后解决。
- 依赖兼容性坑：全新解析会装到 Astro 6.4.8 + Vite 8（rolldown 内核），Tailwind 4.3 的 Vite 插件构建直接失败：`Missing field 'tsconfigPaths' on BindingViteResolvePluginConfig.resolveOptions`。解法是 `astro` 锁精确版 `6.3.7`，并加 `overrides: { vite: "7.3.3" }`，与参考站可用的 vite 7 组合对齐。
- 同时移除已无引用的 `@alpinejs/collapse`（源码改用 `x-transition`），README 中把该项从「未使用依赖」改为「不要引入」。
- 验证：`npm run build` 通过 8 页；CDP 真实时间轴测试菜单 4 次开关（显示 390x471 / 隐藏交替）、弹窗开合与遮罩、语言切换均正常；整页截图确认样式无回归。
- README 技术栈更新为实际安装版本（Astro 6.3.7 / Tailwind 4.3.5 / Alpine 3.17.5 / sharp 0.34.5），并新增「为什么锁死两个版本」小节说明 overrides 来由。
