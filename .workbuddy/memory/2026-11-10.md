## 页脚对齐修复

- 问题（1440 宽）：三列链接列宽由内容决定（仅 98px）挤在左侧，右侧版本卡片被 `justify-between` 推到最右，中间空出 233px 空洞；品牌名因 logo 40px 与 h3 20px 顶对齐，比列标题低约 10px。
- 改法：`Layout.astro` 页脚上半部由「flex + 内层 grid」改为单一五列网格 `lg:grid-cols-[minmax(210px,1.3fr)_repeat(3,minmax(0,1fr))_auto]`；品牌行和三个 h3 统一 `h-10 flex items-center` 保证基线齐平；卡片改 `lg:justify-self-end`。
- 列间距：`lg:gap-x-8`（1024–1279 用 32px，给英文长链接留宽度）、`xl:gap-x-12`（≥1280 用 48px）。实测 1440 四段间距均为 48，1024 均为 32。
- 英文文案 `footer.updateModal.title` 由 `Get the latest TaoSheng`（158px）改为 `Get latest version`，否则 1024 宽下该链接折成两行、破坏列内行距。
- 验证：无头 Chrome 在 1440/1280/1100/1024、中英两种语言下量取列坐标与间距，均匀齐、无元素溢出、无链接折行；390px 移动端堆叠正常，`scrollWidth=390` 无横向溢出。

## 全站链接体检与失效修复

- 站内 13 个链接/资源全部 200；无空 href、无 `#` 锚点、无缺 href 的 `<a>`；4 个按钮（语言、菜单、弹窗开关）实测均生效。
- 站外发现两处 404：
  - `/{repo}/stargazers`：GitHub 对匿名访问已不再提供该页（torvalds/linux 同样 404），改为指向仓库首页 `https://github.com/0xCoach/TaoSheng`（Star 按钮就在那里）。
  - `/{repo}/discussions`：仓库 `has_discussions=false`，页脚、联系页卡片、条款页三处均 404。与用户确认后统一改为 `/issues`，并把文案从「社区讨论 / Discussions」改为「提问与讨论 / Ask questions」、「提问与交流 / Questions & ideas」，与已有的「问题反馈」区分。
- 移动端菜单：`x-collapse`（Alpine 3.17.5）展开后高度停在 0，菜单不可见。对照实验——参考站同样代码用 Alpine 3.15.12 正常（height:auto）；本站 node_modules 是 3.17.5。改为 Alpine 核心 `x-transition`（只保留 enter 动画，收起立即隐藏），并移除 `@alpinejs/collapse` 依赖。
- 验证方式：无头 Chrome 的虚拟时间会让 CSS 过渡卡住、结论失真。改用 Chrome DevTools Protocol（Node 22 内置 WebSocket，`%TEMP%/cdp-check.js`）在真实时间轴下点击验证：菜单 4 次开关在 390/1280 均正确（展开 390x471）、弹窗开/关/点遮罩关闭均正常、语言切换同步 `<html lang>`。
